## Book Ride Flow
- **Mandatory Flow:** When a user selects "Book Ride" (or Schedule Ride), the UI MUST display **predefined routes** (e.g. predefined junctions/stops) for the user to choose their pickup and drop locations.
- **Prohibited Flow:** DO NOT revert to the previous free-form text search or open map-pinning flow for booking a ride. Users must strictly select from the predefined route stops to ensure route matching for drivers.
